# Hangman-Game
A Hangman Game developed in Java with a simple graphical user interface (GUI) using Java Swing. This project integrates core object-oriented programming principles to manage game logic, word selection, and user interaction. It provides a visually engaging and interactive way to play the classic word-guessing game.



### **How to Run the Game and Use It**

1. **Ensure JDK is Installed**: 
   - Download and install the [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/javase-downloads.html) if not already installed.
   - Verify installation by running:
     ```bash
     java -version
     ```

2. **Download the Game Files**:
   - Clone the GitHub repository or download the project as a ZIP file and extract it to a folder.

3. **Open in VS Code**:
   - Open the project folder in Visual Studio Code.
   - Make sure the `Java Extension Pack` is installed in VS Code for smooth Java development.

4. **Compile and Run**:
   - Compile all files using the terminal:
     ```bash
     javac *.java
     ```
   - Run the game by executing the `HangmanGUI` class:
     ```bash
     java HangmanGUI
     ```

5. **Start Playing**:
   - A GUI window will appear.
   - Use the text field to input a letter and press **Submit Guess**.
   - Watch the word and attempts update dynamically.
   - Win by guessing the word or restart the game after losing.
